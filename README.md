# Breeding value theory with genetically differentiated mate pools and imprinting

This repository contains the **R scripts used to simulate data and perform the analyses underlying Figures 2–6** of the manuscript *Breeding value theory with genetically differentiated mate pools and imprinting*.

The code is made available to support transparency and reproducibility of the simulation-based results presented in the manuscript.

## About the manuscript

Breeding value is commonly identified with additive genetic value. These measures are equivalent when the reference population and mate pools share the same allele frequencies and there are no parent-of-origin effects. However, female and male mate pools may differ in allele frequency in breeding programmes, and imprinting may affect the expected genetic value of progeny.

The manuscript examines these relationships using one-locus models with additive, dominance, and imprinting effects, and extends the investigation to multi-locus simulations under antagonistic and synergistic selection. It distinguishes additive genetic value, defined through the within-generation regression of genetic value on allele dosage, from breeding value, defined through the regression of expected progeny genetic value on parental allele dosage. The Price equation is used to connect these breeding-value expressions with changes in mean genetic value under selection.

The R scripts in this repository support the simulations and analyses presented in **Figures 2–6**.

## Repository contents

The repository provides R scripts for:

- simulating the genetic data used in the manuscript;
- conducting the analyses associated with Figures 2–6; and
- generating the corresponding figure-related results.

Refer to the individual scripts for their specific procedures, parameter settings, input files, and outputs.

## Requirements

- [R](https://www.r-project.org/).
- The R packages imported by the scripts.

Check the beginning of each script for its package dependencies (for example, calls to `library()` or `require()`).

### AlphaSimR development version (Figures 5 and 6)

Simulations of multiple loci governed by additive and imprinting effects (Figures 5 and 6) rely on a version of [AlphaSimR](https://github.com/david20011999/AlphaSimR.git) that is still under development and has not been included in the main package available on CRAN. This version can be obtained from the [development GitHub repository](https://github.com/david20011999/AlphaSimR.git).

## Running the scripts

1. Clone or download this repository.
2. Open the R script corresponding to the figure or analysis you wish to reproduce.
3. Check the script comments and file paths, and make sure that the required input files and R packages are available.
4. Run the script in R or RStudio.

Some analyses may depend on simulated data or intermediate files generated by other scripts. In such cases, follow the dependencies and execution order indicated in the relevant scripts.

## Reproducibility

Simulation results may depend on the random-number seeds, R version, package versions, and parameter settings used. For the closest reproduction of the manuscript results, use the settings specified in the scripts and the software environment reported with the final version of the work.
